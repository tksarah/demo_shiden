# Magi × Shiden

Magiが星の魔法でブロックを作り、Shiden Networkへ送り、採用とSDN報酬の受領を喜び、がま口へしまうWebアプリです。SVGと透過画像による45秒のアニメーションで、Shiden Collatorの動きを紹介します。

- **ライブ**：設定したアドレスの確定した自ブロックとPotStakeからの報酬を、公開RPC 2系統で照合して再現。残高も取得します。
- **実績リプレイ**：取得スクリプトのJSON、または対応するGuardian報酬APIのJSONをブラウザーで読み込みます。実績データは同梱していません。
- **架空デモ**：設定不要。音は初期OFFで、一時停止・動き軽減・全画面表示に対応します。

45秒は説明用の演出時間で、実際の送信・検証時間ではありません。新着報酬による主表示の残高更新は収納演出の後に行い、詳細には最新の確定残高を表示します。ウォレット接続・署名・送金は行いません。

## ローカルで起動

Node.js 22.13以降とnpmを使用します。

```sh
git clone https://github.com/tksarah/demo_shiden.git
cd demo_shiden
npm ci
npm run build
npm test
npm start
```

`http://127.0.0.1:4173` を開きます。未設定では架空デモで起動し、RPCには接続しません。

## ライブ・リプレイの設定

`dist/config.example.json` を同じ場所の `config.local.json` としてコピーし、監視対象の**公開アドレス**を記入します。

```json
{
  "walletAddress": "監視するSS58形式の公開アドレス"
}
```

保存後にページを再読み込みするとライブで起動します。空文字または未設定はデモ、不正な設定はエラー表示となり、ライブ取得は開始しません。アドレス変更に再ビルドは不要です。JSONリプレイも同じ設定アドレスの記録だけを受け付けます。

`config.local.json` と `private/` はGit管理外です。ただし、**デプロイした設定ファイルは閲覧者が読み取れます**。秘密鍵・シードフレーズ・パスワードは絶対に記入しないでください。公開サイトに設定すると、監視対象のアドレスと残高を閲覧者が知ることができます。

実績を取得する場合は、設定後に次を実行します。

```sh
node scripts/fetch-chain-replay.mjs 10
```

`private/replay.json` に保存されます。「ライブ / 実績」→「別の記録を読み込む」から読み込んでください。個人の実績ファイルをGitへ追加しないでください。

## デプロイ

1. `npm ci` → `npm run build` → `npm test` を実行します。
2. ライブを使う場合だけ `dist/config.local.json` を用意します。
3. 静的ホスティングの配信ディレクトリーに **`dist/` の中身**を配置します。ルートの `index.html` と、JS・画像・フォントの相対パスを維持してください。

サーバー処理やデータベースは不要です。HTTPSで配信し、ライブ時にはブラウザーからDwellir・Astarの公開RPCへの接続を許可してください。`config.local.json` はキャッシュしない設定にします。実績JSONは配信せず、必要な端末で手動読み込みできます。

GitHubへプッシュするだけではデプロイされません。このリポジトリに自動デプロイや既存Sitesの設定は含めていません。`npm start` はローカル確認用です。

## データと検証

ライブ取得は表示中に約15秒間隔。非表示タブでは休止し、タブを閉じた後の収集・永続保存はありません。最新3件を上映待ちに保持し、古い分は集約します。RPC提供者には端末のIPと照会内容が伝わります。

2系統の公開RPCの一致を確認しますが、ライトクライアントによる暗号学的な確定証明の検証ではありません。未知のruntime・RPC不一致では未確認報酬を上映しません。持ち込みJSONの確認は構造・整合性検査であり、チェーンへの再照会ではありません。

`npm test` は架空データで状態遷移、重複防止、収納後の残高反映、設定、通信失敗と30分相当の再生を確認します。テスト用の架空記録はWeb配信に含めません。

待機中は髪とマントの裾だけを揺らし、脚・靴・体・杖を固定しています。`node scripts/preview-fabric.mjs` を実行して `http://127.0.0.1:4174` を開くと、異なる風の時刻と動き軽減の画像比較を行えます。各固定領域は変更画素数0、髪とマントは変化ありを合格条件にしています。この検証ページは `dist/` に含まれず、ウォレット設定やRPCを使いません。

フォントのライセンスは `dist/assets/fonts/OFL-*.txt` に同梱しています。
